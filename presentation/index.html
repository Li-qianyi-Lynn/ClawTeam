关键技术决策

  • 文件队列 vs 消息中间件 → 文件更简单，零依赖，支持离线
  • Git Worktree 隔离 → 多 Agent 并行修改不冲突
  • Provider-agnostic → Profile + Preset 解耦 Agent 身份与运行时
  • 原子写入（tmp+rename） → 防止并发下数据损坏

项目展示

核心能力

  • 🗂️ 共享任务看板 — 阻塞关系、优先级、进度一目了然
  • 📬 Inbox 消息系统 — Agent 间异步通讯，不依赖实时连接
  • 🌿 Git Worktree 隔离 — 多 Agent 并行改代码，零冲突
  • 📊 Board 实时监控 — TUI 看板 + 浏览器端双模式
  • 🔌 Provider 无关 — Profile 一行切换模型/厂商
  • 🛡️ 高危命令审批 — lifecycle 流程保障生产安全
