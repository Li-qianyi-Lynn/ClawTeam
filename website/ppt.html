技术架构

ClawTeam 三层设计

文件队列 · Git Worktree · 任务图 — 让多 AI 真正并行工作

🔗
协调层
Task Board
共享任务图：优先级、依赖、状态追踪、阻塞自动解除
Inbox Queue
文件队列消息系统，原子写入，Agent 间异步通信
Lifecycle
idle / active / shutdown 状态管理，成本追踪
⚙️
执行层
Git Worktree
每 Agent 独立工作区，并行开发代码不冲突
Spawn Backend
tmux / subprocess 双后端，支持 6+ AI CLI 客户端
Profile System
可复用 provider 配置，模型切换无感
📊
观测层
Board TUI
实时看板：kanban 任务 + inbox 计数 + 消息历史
Context Tools
Git diff/conflicts 检查，跨 worktree 安全交接
6+
支持 AI 客户端

核心设计层次
∞
